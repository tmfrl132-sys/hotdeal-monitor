# 핫딜 모니터

뽐뿌, 클리앙, FM코리아, 유튜브 "정가거부" 채널을 감시합니다. 조건에 맞는 글은 텔레그램으로 링크를 보냅니다.

- **즉시알림:** 쌀먹 등 즉시알림 키워드, 할인율 5% 이상 상품권, 카드 단종 소식, 정가거부 카드 영상
- **묶음 알림 (하루 3번, 08:00 · 12:30 · 19:00):** 추천·댓글이 빨리 붙은 핫딜, 재테크, 알뜰폰 글과 정가거부의 다른 영상

설계: [docs/superpowers/specs/2026-11-13-deal-monitor-design.md](docs/superpowers/specs/2026-11-13-deal-monitor-design.md)

## 0. 바로 써 보기 (텔레그램 없이)

`.env`가 없으면 **로컬 모드**로 동작합니다.

1. `실행.bat`을 더블클릭합니다. 처음 실행할 때는 필요한 프로그램을 자동으로 설치합니다.
2. 브라우저에 알림 페이지(`data/alerts.html`)가 열립니다. 이 페이지는 1분마다 새로고침되고, 🔥 글은 주황색으로 강조됩니다.
3. 알림은 실행 창에도 찍힙니다.
4. 키워드는 다른 명령 창에서 관리합니다. 텔레그램 명령에서 `/`만 뺀 형태입니다.

```
.venv\Scripts\python -m monitor 추가 상품권 컬쳐랜드
.venv\Scripts\python -m monitor 제외 품절
.venv\Scripts\python -m monitor 삭제 컬쳐랜드
.venv\Scripts\python -m monitor 목록
.venv\Scripts\python -m monitor 도움말
```

추가한 키워드는 실행 중인 프로그램에 바로 적용됩니다. 다시 시작할 필요가 없습니다.

나중에 텔레그램을 연결하려면 아래 1~2절대로 `.env`를 만들고 다시 실행합니다. 그때부터는 알림이 텔레그램으로 갑니다.

## 1. 텔레그램 봇 만들기 (처음 한 번)

1. 텔레그램에서 **@BotFather**를 찾아 `/newbot`을 보냅니다.
2. 봇 이름과 아이디(`..._bot`으로 끝나야 함)를 정합니다.
3. BotFather가 알려주는 토큰(`123456:ABC...`)을 복사합니다.
4. 만든 봇과 대화를 열고 아무 말이나 보냅니다.
5. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates`를 엽니다. `"chat":{"id":숫자` 부분의 숫자가 chat_id입니다.

## 2. 설정

`.env.example`을 복사해서 `.env`를 만들고 두 값을 넣습니다. `.env`는 git에 올라가지 않습니다.

```
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_CHAT_ID=987654321
```

기준 숫자(반응 기준, 할인율, 주기, 묶음 시각)와 키워드 사전은 `settings.yaml`에서 바꿉니다. 바꾼 뒤에는 다시 실행해야 적용됩니다.

## 3. 실행 (Windows PC)

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m monitor
```

- 시작하면 텔레그램으로 `🟢 핫딜 모니터 시작`이 옵니다.
- 처음 실행할 때는 지금 올라와 있는 글을 알리지 않습니다. 그 뒤에 새로 올라오는 글부터 알립니다.
- 끄려면 창에서 `Ctrl+C`를 누릅니다.
- 로그는 `logs/monitor.log`에 남고 7일치만 보관합니다. 상태 DB는 `data/monitor.db`입니다.

## 4. 텔레그램 명령

| 명령 | 동작 |
| --- | --- |
| `/추가 쌀먹` | 즉시알림 키워드 추가 (전체 카테고리) |
| `/추가 상품권 컬쳐랜드` | 해당 카테고리에서만 즉시알림 |
| `/제외 품절` | 이 단어가 있으면 보내지 않음 |
| `/삭제 컬쳐랜드` | 키워드 삭제 |
| `/목록` | 키워드 보기 |
| `/일시정지 2시간` | 알림 잠시 끄기 (`30분`, `1시간30분`도 가능) |
| `/재개` | 일시정지 풀기 |
| `/상태` | 소스별 마지막 수집 시각, 오류, 오늘 보낸 수 |
| `/도움말` | 명령 목록 |

카테고리는 재테크, 알뜰폰, 카드, 핫딜, 상품권 중 하나입니다. 영문 명령(`/add`, `/except`, `/del`, `/list`, `/pause`, `/resume`, `/status`, `/help`)도 됩니다.

봇은 `.env`의 chat_id가 보낸 명령에만 응답합니다.

## 알려진 한계

- 뽐뿌 RSS의 반응 수 필드(`[a|b|c|d]`)는 `[댓글|조회|추천|비추천]`으로 가정했습니다. 실제 글과 다르면 `monitor/sources/ppomppu.py` 맨 위의 인덱스만 바꾸면 됩니다.
- 사이트가 화면 구조를 바꾸면 해당 소스가 실패합니다. 3번 연속 실패하면 텔레그램으로 알립니다.
- 유튜브 채널의 커뮤니티 탭 글은 잡지 못합니다.
